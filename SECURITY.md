# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |

## Reporting a vulnerability

Please report security issues via GitHub Security Advisories on
[github.com/chayprabs/grok-pattern-playground](https://github.com/chayprabs/grok-pattern-playground/security/advisories/new)
or email the maintainer via the contact on [chaitanyaprabuddha.com](https://www.chaitanyaprabuddha.com).

Do not open public issues for undisclosed vulnerabilities.

## Scope

GrokParse processes data locally in the browser. Reports about third-party
static hosting misconfiguration are out of scope unless they affect the
repository’s build artifacts.
